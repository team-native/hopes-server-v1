Hopes 개인정보 처리방침

네이티브 팀은 Hopes의 학교 안내, AI 대화, 익명 커뮤니티와 문의 처리에 필요한 정보를 처리합니다. 개인정보 문의와 열람·정정·삭제 요청은 team.native.official@gmail.com으로 보낼 수 있습니다.

1. 처리하는 정보와 목적

구분정보와 사용 목적
계정학교 이메일, 비밀번호의 단방향 해시, 아이디·닉네임, 인증번호와 인증 시각을 학교 구성원 확인, 로그인, 비밀번호 재설정에 사용합니다. 비밀번호 원문은 저장하지 않습니다.
프로필·설정사용자가 제공한 성별, 학과·전공, 기수, 자기소개, 프로필 이미지 URL, 테마, 응답 스타일, 관심 전공과 개인화 동의 상태를 설정 저장과 답변·추천에 사용합니다.
대화·첨부대화 제목, 질문과 답변, 시각, 요청 식별자, 접속 기기 구분, 업로드한 이미지·PDF와 파일 메타데이터를 대화 제공과 재조회, 중복 요청 처리에 사용합니다.
커뮤니티글·댓글·좋아요·신고와 처리 기록을 게시, 신고 확인, 부정 이용 방지에 사용합니다. 일반 이용자에게 작성자 이름·이메일은 공개하지 않습니다. 서버에서는 계정과 게시물을 연결해 소유권을 확인합니다.
문의문의 내용, 답변 이메일, 답변 내용·처리 상태와 시각을 문의 처리에 사용합니다. 답변 이메일을 생략하면 가입 이메일을 사용합니다.
위치위치 비교와 길찾기를 위해 요청한 좌표·측정 시각 또는 선택한 층·도면 좌표를 해당 응답 계산에 사용합니다. 별도의 위치 이력으로 DB에 저장하거나 AI 질문으로 전달하지 않습니다. GPS만으로 층·교실을 확정하지 않습니다.
운영 기록접속 IP, 요청 경로·시각·상태와 오류 정보는 장애 확인과 보안에 사용합니다. 비밀번호·인증 토큰·메일 인증번호·API 키를 운영 로그에 기록하지 않도록 관리합니다.

2. 보관 기간과 삭제

  • 계정과 설정: 회원 탈퇴까지 보관하며 탈퇴 시 서비스 DB에서 삭제합니다.
  • 이메일 인증번호: 유효 시간은 10분이며, 만료된 인증 자료는 매일 정리합니다.
  • 게시글 조회수: 같은 회원의 같은 글 조회를 하루 한 번만 집계하기 위해 게시글 ID·회원 ID·한국 시각 조회 날짜를 임시 보관합니다. 전날까지의 자료는 매일 오전 4시 10분 정리합니다. 회원 탈퇴 시 연결 자료를 삭제하며, 개인을 식별할 수 없는 게시글별 누적 조회수는 유지합니다.
  • 대화와 메시지: 대화의 마지막 변경일부터 365일 또는 사용자의 대화 삭제·회원 탈퇴 중 먼저 도래한 시점까지 보관합니다.
  • 문의와 답변: 문의 접수일부터 365일 또는 회원 탈퇴 중 먼저 도래한 시점까지 보관합니다.
  • 기간이 지난 대화·문의는 매일 한국 시각 오전 4시 10분 정리합니다. 정리 시점에 따라 보관 기간 종료 후 최대 하루의 처리 시간이 추가됩니다.
  • 첨부 원본: 업로드일부터 30일 동안 열람할 수 있습니다. 만료되거나 대화·계정이 삭제되면 파일 정리 작업으로 삭제하며, 파일 시스템 정리에 최대 2시간이 추가될 수 있습니다. 파일 메타데이터는 연결된 대화의 보관 기간을 따릅니다.
  • 커뮤니티 글·댓글: 작성자가 삭제하거나 탈퇴할 때까지 보관합니다. 탈퇴 시 작성 글·댓글은 삭제합니다. 신고 당시 저장한 증거 사본은 별도 보관할 수 있으며, 신고 처리 완료·기각일부터 365일이 지나면 매일 정리합니다. 처리 중인 신고는 처리가 끝날 때까지 보관합니다.
  • 백업: 서버 DB 백업과 외부 암호화 백업은 30일 보관 후 정리합니다. 탈퇴·삭제 내용이 이미 생성된 백업에 즉시 반영되지는 않으며, 백업은 서비스 운영 데이터로 다시 사용하지 않습니다. 복원 시 삭제 요청을 재반영해야 합니다.

3. AI·이메일·운영 서비스 이용

AI 답변을 위해 현재 Google Gemini API를 사용합니다. OpenAI API의 키·모델이 설정되면 OpenAI를 사용할 수 있으며, 설정이 없으면 Gemini를 사용합니다. 질문, 답변에 필요한 최근 대화, 선택한 전공, 프로필·응답 스타일과 사용자가 보낸 첨부 내용이 선택된 AI 공급자에게 전달될 수 있습니다. API 호출에는 학교 이메일과 비밀번호를 자동으로 포함하지 않습니다. 질문·자기소개·첨부에 직접 적은 개인정보는 함께 전달될 수 있으므로 불필요한 민감정보를 입력하지 마세요.

인증·문의 답변 메일은 Google Gmail SMTP로 발송합니다. 수신 이메일, 인증번호 또는 답변 내용이 메일 전송을 위해 처리됩니다. 실제 발신 계정과 무관하게 문의 답변 메일의 회신 주소는 팀 공식 연락처입니다.

질문 품질 점검을 위해 Discord 운영 채널에 질문 내용(최대 4,000자), 대화 ID, 앱·웹 구분과 시각이 별도로 전송될 수 있습니다. Discord 메시지는 서비스 DB 삭제와 자동 연동되지 않는 별도 운영 기록입니다. 해당 기록의 확인·삭제 요청은 팀 공식 연락처로 보내주세요. 서비스 DB의 365일 자동 삭제가 이 외부 기록까지 삭제한다고 안내하지 않습니다.

암호화 DB 백업은 GitHub Actions의 제한된 저장소 아티팩트에 30일 보관합니다. 복구용 개인키는 백업과 분리해서 관리합니다.

4. 국외 서비스 처리 안내

Google LLC, OpenAI, Discord Inc., GitHub, Inc. 등 미국 기반 공급자의 API·메일·운영 서비스를 사용하므로 위 정보가 HTTPS 또는 암호화된 메일 연결을 통해 국외 서비스로 전송될 수 있습니다. 공급자의 실제 처리 지역과 보관·삭제 조건은 계약·계정 설정에 따라 달라집니다. 국외 전송을 원하지 않으면 해당 AI·첨부·메일 기능 사용을 중단하고 팀 공식 연락처로 대체 처리와 삭제를 요청할 수 있습니다.

Gemini는 유료·무료 서비스 조건에 따라 입력의 제품 개선 사용 여부 등이 달라집니다. 무료 서비스에서는 입력·출력이 제품 개선과 사람 검토에 사용될 수 있습니다. 이 서비스가 무보관 또는 학습 미사용 계약을 체결했다고 보장하지 않습니다. 공급자 안내: Gemini 약관, Gemini 데이터 보관 안내, OpenAI API 데이터 안내, Discord 개인정보 처리방침, GitHub 개인정보 처리방침.

5. 이용자의 권리와 보호 조치

앱의 계정·대화 설정에서 프로필 수정, 대화 삭제와 회원 탈퇴를 할 수 있습니다. 추천 개인화 동의는 설정에서 철회할 수 있습니다. 별도 열람·정정·삭제·처리정지 요청은 본인 확인 후 처리하며, 신고 증거 등 별도 보관이 필요한 자료가 있으면 사유와 처리 범위를 안내합니다. 계정 소유자 확인 없이 다른 사람의 계정 정보는 제공하지 않습니다.

HTTPS 전송, 비밀번호 해시, 사용자별 접근 검사, 운영자 권한 분리, 비공개 첨부 저장, 외부 백업 암호화와 보관 기간 정리를 적용합니다. 정보가 필요한 운영자에게만 접근을 허용합니다.
